# Examenpractico_intro

## Presentacion de los integrantes del equipo 

## Asignatura
Introduccion a la ingenieria en software

## Proyecto
Jovenes en accion-perfiles de integrantes

## Descripción del proyecto
Consiste en la creación de un repositorio público en Github que contiene la presentación del equipo mediante un perfil relacionado con el programa Jóvenes en acción, donde se incluirá la información de los integrantes. Este espacio web permitirá organizar y visualizar la informacion del proyecto. Además, se demostrará el uso del Git y Github para gestionar cambios con los archivos,registrar modificaciones mediante los commits  y desarrollar actividades colaborativas entre los integrnates del grupo. 

## Objetivo del proyecto 
Desarrollar un espacio web que permita presentar y visualizar la información de los integrantes del equipo, aplicando herramientas de desarrollo y gestión de archivos para facilitar el trabajo colaborativo.
